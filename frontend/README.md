# VehicleChain

Historial vehicular verificable — Entregable 3: Functional Proof.

## Requisitos

```text
Node.js 20+
npm 10+
Git
```

## Instalación

```bash
git clone <URL_DEL_REPOSITORIO>
cd vehiclechain/frontend
npm install
```

## Cómo correrlo

```bash
npm run dev
```

Luego abrir:

```text
http://localhost:5173
```
